# WHO TB Catalogue Tool

A single-page, self-contained copy of the WHO TB mutation catalogue tool
from the [DrDx.Me](https://www.drdx.me) offline tool suite, published here
so it can be opened as a webpage via GitHub Pages rather than downloaded.

This repo holds only the built output. 

WHO catalogue data is used under its CC BY-NC-SA (non-commercial) licence;
see the notice inside the page itself.
